# Требования к порталу мастерской

## Таблица №1 – Роли

| Роль | Описание | Ключевые функции |
|------|----------|------------------|
| Клиент | Пользователь сервиса, оставляющий заявку на ремонт техники | Регистрация, вход, создание заявки, просмотр своих заявок и их статусов |
| Мастер-администратор (adminka / password) | Сотрудник мастерской, обрабатывающий заявки | Просмотр всех заявок, смена статусов заявок, указание стоимости ремонта, отклонение заявок с указанием причины |

## Таблица №2 – Страницы

| Страница (файл) | Кто видит | Что на ней |
|-----------------|-----------|------------|
| register.html | Неавторизованный пользователь | Форма регистрации: логин, пароль, ФИО, телефон, email; кнопка «Зарегистрироваться» |
| login.html | Неавторизованный пользователь | Форма входа: логин, пароль; кнопка «Войти» |
| client_dashboard.html | Клиент | Список заявок клиента с их статусами; кнопка «Создать заявку» |
| create_request.html | Клиент | Форма заявки: вид техники, описание неисправности, адрес/самовывоз, желаемая дата; кнопка «Отправить» |
| client_request_view.html | Клиент | Детали конкретной заявки: вид техники, описание, адрес, дата, текущий статус, стоимость (если указана) |
| admin_dashboard.html | Мастер-администратор | Список всех заявок с фильтрацией/сортировкой; переход к редактированию заявки |
| admin_request_edit.html | Мастер-администратор | Детали заявки; выбор статуса (Диагностика / В ремонте / Готово к выдаче / Отклонено); поле причины отклонения; поле стоимости ремонта; кнопка «Сохранить» |

## Таблица №3 – Поля и правила

| Поле | Где используется | Правила |
|------|------------------|---------|
| Логин | Регистрация | Латиница, не короче 6 символов, уникальный |
| Пароль | Регистрация / Вход | Не короче 6 символов |
| ФИО | Регистрация | Кириллица |
| Телефон | Регистрация | Формат +7(XXX)-XXX-XX-XX |
| Email | Регистрация | Валидный формат email |
| Вид техники | Создание заявки | Один из: смартфон, ноутбук, планшет, другое (если «другое» — обязательно описание) |
| Описание неисправности | Создание заявки | Обязательное поле |
| Адрес / Самовывоз | Создание заявки | Либо адрес, либо признак самовывоза в мастерскую |
| Желаемая дата | Создание заявки | Дата не может быть в прошлом |
| Статус заявки | Заявка | Значения: Новая, Диагностика, В ремонте, Готово к выдаче, Отклонено |
| Причина отклонения | Редактирование заявки админом | Обязательна при статусе «Отклонено» |
| Стоимость ремонта | Редактирование заявки админом | Число ≥ 0; может быть указана не сразу |

## Таблица №4 – Неявные требования

| № | Неявное требование | Из какой фразы следует |
|---|--------------------|------------------------|
| 1 | Клиент не должен видеть заявки других клиентов | «Клиент видит свои заявки и их статусы» |
| 2 | При статусе «Отклонено» поле причины обязательно для заполнения | «Отклонено (с указанием причины)» |
| 3 | Система должна проверять уникальность логина при регистрации | «логин … уникальный» |
| 4 | Дата заявки не может быть в прошлом | «желаемая дата» |
| 5 | Если выбран вид техники «другое», поле описания техники обязательно | «другое — с описанием» |
| 6 | Стоимость ремонта может быть указана не сразу | «указать стоимость ремонта» |
